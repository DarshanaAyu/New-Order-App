📥 Export as CSV

Download your entire medicine catalogue as a CSV file. You can open it in Excel or Google Sheets, edit prices, and re-import it.

📋 CSV Format Reference

The CSV uses these columns. Quantity/price columns are flexible — any number of pairs are supported. supplier_code must match a code from your Suppliers page (e.g. DES, SWA, SID). The category value must match one of the categories below (not case-sensitive).

supplier_code,name,category,qty_1,price_1,qty_2,price_2,... Valid categories: Kashaya, Guli/Tablets, Kalka, Churna, Oils, Pattu, Pattu Churna, Asava/Arishta/Peni Examples: DES,Dhanwantaram,Kashaya,250g,1670,500g,3120,1Kg,5790 DES,Brahmi Guli,Guli/Tablets,60 Qty,440,250 Qty,1670,1000 Qty,5790 SWA,Yashtimadhu Kalka,Kalka,250g,1450,500g,2780,1Kg,5200 SWA,Triphala Churna,Churna,250g,320,500g,590,1Kg,1100 SID,Karpasasthyadi Thailaya,Oils,100ml,580,200ml,990,500ml,2450,1L,4230,2L,8050 SID,Jathyadi Pattu,Pattu,25g,650,50g,1180,100g,2150 DES,Triphala Pattu Churna,Pattu Churna,100g,480,300g,1320,1Kg,4100 DES,Dashamoolarishta,Asava/Arishta/Peni,200ml,420,450ml,820,750ml,1280
